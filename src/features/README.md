## Cross-domain rules

- Put a user-facing component with its domain; do not create a new feature
  folder for one helper.
- Put typed invoke wrappers in `src/lib/api/`, not inline in components.
- `src/App.tsx` may coordinate domains, but domain-specific projection and
  state-machine logic belongs in its feature folder with focused tests.
- Browser, session, context, and project identities must move together. A stale
  async response from one identity must never repaint another.
- Library connections never add context. Only the explicit shelf/drop actions
  add an opaque eligible ref.
