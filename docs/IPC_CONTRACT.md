# IPC Contract

Source of truth for the Tauri IPC surface. Every command and event listed
here has a stable shape; anything not listed is not part of the contract
yet. See `docs/ARCHITECTURE.md` for how this surface fits into the process
model.

## Request envelope

Every invoke takes a uniform envelope so the version is always enforced
the same way:

```rust
#[derive(Debug, serde::Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct IpcRequest<T> {
    pub ipc_version: u32,
    pub payload: T,
}
```

The `rename_all = "camelCase"` is load-bearing: TS sends `ipcVersion`,
Rust holds `ipc_version`. Apply the same convention to every other
struct in this contract that crosses the boundary.

```ts
type IpcRequest<T> = { ipcVersion: 1; payload: T };
```

The backend rejects unknown majors with `IpcError::Version` before any
handler runs. Bumping the major requires a doc change here, a backend
handler bump, and a frontend bump.

Events do **not** carry `ipcVersion`. They are emitted under an
already-versioned command/session, so the envelope's version applies
to the whole stream a command spawns.

## Error model

Every command returns `Result<T, IpcError>` on the Rust side, surfaced to
TS as a `Promise<T>` that rejects with the same shape.

```rust
#[derive(Debug, thiserror::Error, serde::Serialize)]
#[serde(tag = "kind", content = "details")]
pub enum IpcError {
    #[error("path is outside project root: {0}")]
    PathEscape(String),
    #[error("path not found: {0}")]
    NotFound(String),
    #[error("operation requires user approval")]
    NeedsApproval,
    #[error("operation cancelled")]
    Cancelled,
    #[error("provider {provider} unavailable: {reason}")]
    ProviderDown { provider: String, reason: String },
    #[error("invalid argument: {0}")]
    BadArgument(String),
    #[error("internal: {0}")]
    Internal(String),
    #[error("ipc version mismatch (frontend wants {wanted}, backend speaks {speaks})")]
    Version { wanted: u32, speaks: u32 },
}
```

```ts
type IpcError =
  | { kind: 'PathEscape';   details: string }
  | { kind: 'NotFound';     details: string }
  | { kind: 'NeedsApproval' }
  | { kind: 'Cancelled' }
  | { kind: 'ProviderDown'; details: { provider: string; reason: string } }
  | { kind: 'BadArgument';  details: string }
  | { kind: 'Internal';     details: string }
  | { kind: 'Version';      details: { wanted: number; speaks: number } };
```

Components match on `kind`; never parse `message`.

## IDs

| Kind            | Type     | Generated by | Lifetime                              |
| --------------- | -------- | ------------ | ------------------------------------- |
| `ChatStreamId`  | `string` | backend      | until `chat.done` or `chat.cancel`    |
| `RunHandle`     | `string` | backend      | until `cmd.exit` or `commands.cancel` |
| `ServerHandle`  | `string` | backend      | until `providers.stopServer`          |
| `ProjectId`     | `string` | backend      | window lifetime                       |

All IDs are opaque ULIDs. The frontend does not parse them.

## Cancellation

Every long-running command has a paired `cancel` that takes the ID and
returns `Result<(), IpcError>`. Cancellation is best-effort and
idempotent: cancelling a finished operation succeeds silently. A
cancelled stream emits a final event with `finish: 'cancelled'` before
its ID becomes invalid.

## Event sequencing

Streamed events carry `seq`, a monotonically increasing `u64` per stream
ID starting at 0. The frontend buffers out-of-order events and drops
duplicates. If `seq` skips a value, the frontend marks the stream as
corrupt and surfaces an error rather than silently continuing.

## v0 command surface

Every command below actually takes `IpcRequest<Payload>` and returns
`Result<Response, IpcError>`. Only the payload and response shapes are
listed here, for readability. A command shown as `foo.bar()` takes
`IpcRequest<{}>`.

### project

```
project.open(path: string)        -> ProjectMeta
project.refresh()                 -> ProjectMeta

type ProjectMeta = {
  id: ProjectId;
  root: string;                   // canonicalized absolute path
  hasAgentsMd: boolean;
  hasClaudeMd: boolean;
  packageManagers: ('npm' | 'pnpm' | 'yarn' | 'cargo' | 'pip')[];
  git: { branch: string | null; dirtyCount: number } | null;
};
```

### fs

```
fs.read(path: string)
  -> { content: string; encoding: 'utf-8' | 'binary'; bytes: number }

fs.list(path: string)
  -> FileEntry[]

type FileEntry = {
  name: string;
  path: string;                   // canonicalized absolute
  kind: 'file' | 'dir' | 'symlink';
  size: number | null;
  modifiedMs: number;
};
```

`fs.read` rejects with `PathEscape` outside the open project root.
Binary files return `encoding: 'binary'` with an empty `content`; a
separate (deferred) command will fetch raw bytes when needed.

### git

```
git.status() -> GitStatus

type GitStatus = {
  branch: string | null;
  ahead: number;
  behind: number;
  staged: GitFile[];
  unstaged: GitFile[];
  untracked: GitFile[];
};

type GitFile = { path: string; status: 'added' | 'modified' | 'deleted' | 'renamed' };
```

### chat

```
chat.send(req: ChatRequest)       -> ChatStreamId
chat.cancel(id: ChatStreamId)     -> void

type ChatRequest = {
  providerId: string;
  modelId: string;
  mode: 'chat' | 'propose-diff' | 'scoped-edit' | 'agent';
  instruction: string;
  attachments: Attachment[];
  // Backend assembles the final prompt from these.
  // Frontend never sees raw file content.
};

type Attachment =
  | { kind: 'file';      path: string }
  | { kind: 'selection'; path: string; range: [number, number] };

// Events under stream id `cs`:
//   chat.token { id: cs, seq, token: string }
//   chat.done  { id: cs, seq, finish: 'stop' | 'length' | 'tool' | 'cancelled' | 'error',
//                tokensIn: number, tokensOut: number, ms: number }
//   chat.tool  { id: cs, seq, name: string, args: Json }   // agent mode only
```

### commands

```
commands.detect()                              -> CommandSuggestion[]
commands.run({ argv: string[]; approved })     -> RunHandle
commands.cancel(handle: RunHandle)             -> void

type CommandSuggestion = {
  source: 'package.json' | 'cargo.toml' | 'pyproject.toml' | 'verify.sh';
  argv: string[];
  label: string;
};

// Events under run handle `rh`:
//   cmd.line { handle: rh, seq, stream: 'stdout' | 'stderr', line: string }
//   cmd.exit { handle: rh, seq, code: number | null, signal: string | null }
```

`commands.run` rejects with `NeedsApproval` when `approved: false` and
the exact normalized argv is not in the project's approval ledger (see
`docs/SAFETY.md`).

### patch

```
patch.validate(diff: string)
  -> { ok: true; touches: string[] } | { ok: false; errors: string[] }

patch.apply(diff: string)
  -> { applied: string[]; checkpoint: string | null }
```

`patch.apply` rejects with `PathEscape` if any hunk targets a path
outside the project root, or `BadArgument` if any pre-image does not
match disk.

### providers

```
providers.list()                               -> ProviderInfo[]
providers.installed(id: string)                -> boolean
providers.startServer(id, modelId)             -> ServerHandle
providers.stopServer(handle: ServerHandle)     -> void

type ProviderInfo = {
  id: string;
  displayName: string;
  capabilities: ProviderCapabilities;          // see docs/MODEL_PROVIDERS.md
};
```
